# 최종 상태 기준 작성 규칙 (이력 흔적·정정 주석 금지)

## 목차
1. 목적
2. 핵심 원칙 (최종 상태만 남긴다)
3. 금지 대상 (남기지 말 것)
4. 허용 대상 (남겨도 되는 것)
5. 코드/문서별 적용
6. 변경 이력은 어디에 남기는가
7. 실행 체크리스트

## 1. 목적

- 작업 결과물(코드·문서)은 **"어떻게 바뀌어 왔는지"가 아니라 "지금 무엇인지"**를
  기준으로 깔끔하게 작성한다.
- 작업 과정의 흔적(배너, 정정 주석, 옛 버전 병기)은 결과물을 어지럽히고
  오해를 유발하므로 남기지 않는다.
- 독자가 결과물만 보고 **최종 결정 사항을 바로 이해**할 수 있게 한다.

## 2. 핵심 원칙 (최종 상태만 남긴다)

- 결과물은 **최종 결정만 반영**한다. 중간에 폐기된 안, 되돌린 변경, 시도했다
  버린 접근은 결과물에 남기지 않는다.
- 무언가를 바꿨으면 **바꾼 결과로 대체**할 뿐, "예전에는 이랬다"를 병기하지 않는다.
- 삭제할 코드는 주석 처리해서 남기지 말고 **실제로 삭제**한다.
  (되돌릴 필요가 있으면 버전 관리 이력이 그 역할을 한다.)

## 3. 금지 대상 (남기지 말 것)

작업 산출물(코드·문서)에 아래를 남기지 않는다.

- **배너/구분선 주석**: `==== 수정 시작 ====`, `--- 여기부터 변경 ---` 등
- **정정·해명 주석**: "기존 로직 제거함", "원래 A였으나 B로 변경", "TODO였는데 처리함"
- **이력 흔적**: 날짜/작성자/차수를 코드 안에 나열하는 변경 로그성 주석
- **옛 코드 병기**: 주석 처리된 이전 구현, `// old:` 블록
- **작업 과정 메모**: "일단 이렇게", "임시", "테스트용" 같은 잔재
- **문서 내 정정선/취소선**으로 옛 내용을 남기는 것 (최종본으로 교체)

## 4. 허용 대상 (남겨도 되는 것)

이력·정정 흔적과 달리, 아래는 **최종 상태를 설명**하므로 허용한다.

- 현재 코드의 동작·의도·주의점을 설명하는 주석
- 복잡한 로직의 "왜"를 설명하는 근거 주석 (단, 과거형 "예전엔" 금지)
- 공개 API의 계약·파라미터·예외를 기술하는 문서 주석
- 외부 이슈/스펙 링크 등 현재도 유효한 참조

기준: **"지금 이 코드를 이해하는 데 필요한가"** 이면 허용, **"과거를
기록하는가"** 이면 금지.

## 5. 코드/문서별 적용

### 코드
- 리팩터링 후 옛 함수/분기는 주석이 아니라 삭제로 처리한다.
- diff를 설명하는 주석을 코드에 심지 않는다. 설명은 커밋 메시지/PR에.

### spec 문서 (requirements/design/tasks 등)
- 합의가 바뀌면 해당 항목을 **최종 결정으로 덮어쓴다.** "원안 → 변경안"을
  나란히 남기지 않는다.
- "이전 버전에서는" 같은 서술 대신 현재 확정된 내용만 기술한다.

### changes.md 성격의 문서
- 변경 요약 문서는 예외적으로 "무엇을 바꿨는지" 기록이 목적이므로,
  6절 기준에 따라 이력을 남긴다.

## 6. 변경 이력은 어디에 남기는가

이력을 아예 없애자는 것이 아니라, **결과물이 아닌 올바른 장소**에 남긴다.

- **버전 관리(git, svn) 커밋/PR**: 무엇을 왜 바꿨는지의 1차 기록.
- **전용 변경 문서**(`changes.md`, `CHANGELOG` 등): 이력 기록이 목적인 문서.
- **spec의 별도 이력 섹션**: 필요 시 문서 하단에 모아 기록.
- **docs의 스펙 문서 정리**: 필요 시 문서 하단에 모아 기록.

→ 결과물(소스/설계 본문)에는 최종 상태만, 이력은 위 장소에 분리한다.

## 7. 실행 체크리스트

- [ ] 산출물에 배너/구분선 주석을 넣지 않았는가
- [ ] "원래 A였으나 B로" 같은 정정 주석을 넣지 않았는가
- [ ] 삭제 대상을 주석 처리로 남기지 않고 실제 삭제했는가
- [ ] 코드/설계 본문에 날짜·작성자·차수 이력을 심지 않았는가
- [ ] spec 문서를 최종 결정으로 덮어썼는가 (원안 병기 금지)
- [ ] 남긴 주석이 과거 기록이 아니라 현재 이해를 돕는 것인가
- [ ] 이력이 필요하면 커밋/PR/전용 문서로 분리했는가
